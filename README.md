# 🌱 AgroQuest – Site de Apresentação do Jogo

O **AgroQuest** é um projeto acadêmico desenvolvido no curso de **Tecnologia em Jogos Digitais**, com o propósito de apresentar e divulgar um jogo digital com temática voltada ao agronegócio.

A plataforma web foi concebida como um ambiente de apresentação do jogo, reunindo informações sobre sua proposta, seus objetivos e seu desenvolvimento, proporcionando aos visitantes uma visão geral do projeto.

Além de atender aos objetivos acadêmicos, o projeto foi estruturado com uma perspectiva de continuidade e colaboração, sendo disponibilizado como referência para as próximas turmas do curso. Dessa forma, novos estudantes poderão conhecer a iniciativa, explorar sua estrutura, propor melhorias e contribuir para sua evolução.

## 🎯 Objetivos do Projeto

- Apresentar e divulgar o jogo digital desenvolvido com temática voltada ao agronegócio.
- Demonstrar a aplicação prática dos conhecimentos adquiridos durante a formação acadêmica.
- Desenvolver um ambiente web para apresentação e divulgação do projeto.
- Documentar e disponibilizar a estrutura do projeto como material de referência.
- Possibilitar a continuidade do desenvolvimento por futuras turmas.
- Incentivar a colaboração, o compartilhamento de conhecimento e a evolução do projeto.

## 🎓 Contexto Acadêmico

O projeto integra as atividades práticas do curso de **Tecnologia em Jogos Digitais**, contemplando a aplicação de conhecimentos relacionados ao desenvolvimento web e à apresentação de produtos digitais.

Sua disponibilização no GitHub tem como finalidade preservar o trabalho desenvolvido, facilitar o acesso à sua estrutura e proporcionar às próximas turmas uma base de estudos e desenvolvimento.

## 🚀 Continuidade do Projeto

O AgroQuest foi concebido para ir além de uma entrega acadêmica. Seu repositório permanecerá como referência para futuros estudantes, incentivando novas contribuições, atualizações e melhorias.

**A proposta é transformar o conhecimento desenvolvido em sala de aula em um legado acadêmico, permitindo que cada nova turma possa aprender, colaborar e contribuir para a evolução do projeto.**
